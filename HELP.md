# Getting Started

This project runs on Java 21 and Spring Boot 4.1.1. Build it with the Maven wrapper
(`./mvnw -B clean verify`); see `README.md` for setup and `MIGRATION_NOTES.md` for the upgrade history.

## Reference Documentation

For further reference, please consider the following sections:

* [Official Apache Maven documentation](https://maven.apache.org/guides/index.html)
* [Spring Boot 4.1 Reference](https://docs.spring.io/spring-boot/4.1/index.html)
* [Spring Boot 4.0 Migration Guide](https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-4.0-Migration-Guide)
* [Spring Security 7 Migration](https://docs.spring.io/spring-security/reference/migration/index.html)
